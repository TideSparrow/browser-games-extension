# Browser Game Hub – Game Finder Privacy Policy

The extension does not collect or transmit personal information. Search terms, category filters, and random picks are processed in the popup. Favorites are stored locally in Chrome and can be removed by unmarking them or uninstalling the extension.

The extension does not read browsing history, cookies, or page contents. It has no analytics requests of its own. If you choose a link, Chrome opens Browser Game Hub in a new tab. The link includes campaign parameters that identify which extension control opened the website. Search terms and favorites are never included. The website is subject to its own [privacy policy](https://browsergamehub.net/privacy).

For questions about the extension, use the [project issue tracker](https://github.com/TideSparrow/browser-games-extension/issues).

## 简体中文

插件不收集或传输个人信息。搜索、分类筛选和随机选择在弹窗内完成。收藏保存在当前浏览器中，可以取消收藏或卸载插件来清除。

插件不读取浏览历史、Cookie 或网页内容，也不发送自己的统计请求。点击链接时，Chrome 会在新标签页中打开官网。链接携带的渠道参数只用于标识入口，不包含搜索词或收藏数据。访问官网时适用 [网站隐私政策](https://browsergamehub.net/privacy)。

插件相关问题可通过 [GitHub Issue](https://github.com/TideSparrow/browser-games-extension/issues) 反馈。
